✅ SOLUTION 3: Use Firefox Instead of Chrome
═══════════════════════════════════════════════════════════════════

If you have Firefox installed:

1. Install geckodriver:
   pip install webdriver-manager

2. Modify the code to use Firefox:
   Replace: webdriver.Chrome()
   With: webdriver.Firefox()

═══════════════════════════════════════════════════════════════════

✅ SOLUTION 4: Use Edge Browser (Windows)
═══════════════════════════════════════════════════════════════════

Windows 10/11 has Edge pre-installed:

1. Install edge driver:
   pip install msedge-selenium-tools

2. Modify code to use Edge:
   from msedge.selenium_tools import Edge, EdgeOptions
   options = EdgeOptions()
   self.driver = Edge(options=options)

═══════════════════════════════════════════════════════════════════

✅ SOLUTION 5: Specify Chrome Path Manually
═══════════════════════════════════════════════════════════════════

If Chrome IS installed but not found:

Add this line in setup_driver():

chrome_options.binary_location = "YOUR_CHROME_PATH"

COMMON PATHS:

Windows:
  C:/Program Files/Google/Chrome/Application/chrome.exe
  C:/Program Files (x86)/Google/Chrome/Application/chrome.exe

Linux:
  /usr/bin/google-chrome
  /usr/bin/chromium-browser

Mac:
  /Applications/Google Chrome.app/Contents/MacOS/Google Chrome
