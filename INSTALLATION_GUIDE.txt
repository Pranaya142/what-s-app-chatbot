🚀 STEP-BY-STEP INSTALLATION

═══════════════════════════════════════════════════════════════════

STEP 1: VERIFY PYTHON
──────────────────────────────────────────────────────────────────

Open Command Prompt and type:

    python --version

You should see: Python 3.7.x or higher

If not installed, download from: https://www.python.org/downloads/

═══════════════════════════════════════════════════════════════════

STEP 2: INSTALL DEPENDENCIES
──────────────────────────────────────────────────────────────────

Open Command Prompt in the WhatsAppAutoReply folder:

    cd C:/WhatsAppAutoReply
    pip install -r requirements.txt

This installs:
  • Selenium (for browser automation)
  • WebDriver Manager (for Chrome driver)

═══════════════════════════════════════════════════════────════════

STEP 3: VERIFY CHROME BROWSER
──────────────────────────────────────────────────────────────────

Make sure you have Google Chrome installed.

Download from: https://www.google.com/chrome/

═══════════════════════════════════════════════════════════════════

STEP 4: FIRST RUN
──────────────────────────────────────────────────────────────────

Run the bot:

    python whatsapp_auto_reply.py

What happens:
  1. Chrome opens with WhatsApp Web
  2. QR code appears
  3. Scan with your phone (WhatsApp > Menu > Linked Devices)
  4. Bot starts automatically!

🎯 HOW IT WORKS

═══════════════════════════════════════════════════════════════════

1. Bot opens WhatsApp Web in Chrome
2. You scan QR code (first time only)
3. Bot monitors for unread messages
4. Detects message type (birthday, good morning, etc.)
5. Generates appropriate reply
6. Sends reply automatically
7. Logs conversation in message_history.json

⚙️ CONFIGURATION OPTIONS

═══════════════════════════════════════════════════════════════════

CHECK INTERVAL
──────────────────────────────────────────────────────────────────
Default: 10 seconds (checks for new messages every 10 seconds)

To change, edit main() function:

    bot.run(check_interval=15)  # Check every 15 seconds

Recommendations:
  • 10 seconds: Responsive, higher CPU usage
  • 20 seconds: Balanced
  • 30 seconds: Battery-friendly

RESPONSE TEMPLATES
──────────────────────────────────────────────────────────────────
Located in: self.response_templates dictionary

Add your own:

    'birthday': [
        "Thanks a ton! 🎂",

        "So grateful for your wishes! 🎁"
    ]

Add more in detect_message_type() function!

🔧 TROUBLESHOOTING

═══════════════════════════════════════════════════════════════════

PROBLEM: "Selenium not found"
──────────────────────────────────────────────────────────────────
SOLUTION:
    pip install selenium

PROBLEM: "ChromeDriver not found"
──────────────────────────────────────────────────────────────────
SOLUTION:
    pip install webdriver-manager

PROBLEM: Chrome doesn't open
──────────────────────────────────────────────────────────────────
SOLUTION:
  • Install Google Chrome
  • Check if Chrome is in default location
  • Try running as administrator

PROBLEM: QR code doesn't appear
──────────────────────────────────────────────────────────────────
SOLUTION:
  • Wait 30-60 seconds
  • Check internet connection
  • Clear Chrome cache
  • Delete User_Data folder and retry

PROBLEM: Bot doesn't detect messages
──────────────────────────────────────────────────────────────────
SOLUTION:
  • Increase check_interval
  • Check if messages are marked as unread
  • Verify WhatsApp Web loaded completely

PROBLEM: Messages not sending
──────────────────────────────────────────────────────────────────
SOLUTION:
  • Check internet connection
  • Verify you're logged in to WhatsApp Web
  • Try manual send to test

PROBLEM: "Session expired"
──────────────────────────────────────────────────────────────────
SOLUTION:
  • Delete User_Data folder
  • Scan QR code again
