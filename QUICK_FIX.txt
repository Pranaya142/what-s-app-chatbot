🔧 TROUBLESHOOTING STEPS
═══════════════════════════════════════════════════════════════════

IF ERROR PERSISTS:

1. CHECK CHROME IS INSTALLED
   Open Chrome browser manually
   Check version: Chrome > Help > About

2. UPDATE PACKAGES
   pip install --upgrade selenium webdriver-manager

3. DELETE USER DATA
   Delete "User_Data" folder
   Scan QR code again

4. CHECK PYTHON VERSION
   python --version
   Should be 3.7+

5. RUN AS ADMINISTRATOR
   Right-click > Run as administrator

6. DISABLE ANTIVIRUS TEMPORARILY
   Some antivirus blocks WebDriver
