HOW TO USE - 2 METHODS
============================================================

METHOD 1: Double-Click (EASIEST)
--------------------------------
1. Double-click: START.bat
2. Press ENTER
3. When you get a WhatsApp message:
   - Copy the message (Ctrl+C)
   - Paste here (Ctrl+V)
   - Press ENTER
4. Bot suggests reply
5. Copy reply and send on WhatsApp!

METHOD 2: Command Line
--------------------------------
1. Open Command Prompt
2. Type: cd C:\WhatsAppAutoReply
3. Type: python whatsapp_simple_reply_fixed.py
4. Follow the prompts!

EXAMPLE USAGE
============================================================

You receive: "Happy Birthday! Hope you have a great day!"

  Detected Type: Birthday
